Todo - A lightweight project todo list

**Usage:**

  todo add TEXT...
  todo list FILTER...
  todo edit ID[/ID...] [TEXT...]
  todo del ID[/ID...]|+TAG
  todo help

**Aliases:**

  todo new = todo add
  todo ls  = todo list
  todo rm  = todo del

**Task syntax:**

  WORD...  description text
  +TAG     add a tag
  -TAG     remove a tag
  +ID      add a task connection
  -ID      remove a task connection

After `+` or `-`, an all-digit value is a connection; any other valid value is a
tag. Tags begin with a letter or digit and may also contain hyphens or
underscores. A prefix is special only when the whole token matches this syntax:
`+tag` adds a tag, while the separate words `+ tag` are ordinary text. Invalid
operations and standalone `+`, `-`, or `--` are also ordinary text. Valid
operations have the same meaning in every command; removals during `todo add`
are accepted and have no effect.

During `todo edit`, ordinary text replaces the description. When an edit contains
only tag and connection operations, the existing description remains unchanged.
With no text, `todo edit ID` opens the current description, tags, and connections
in $EDITOR (default: vi). Newlines and other whitespace are normalized to spaces.
Multiple IDs separated by `/` receive the same non-interactive edit atomically.
`todo del` prints every removed task so it can be recovered if needed. Passing
multiple IDs separated by `/` deletes them atomically. Passing `+TAG` deletes all
tasks with that exact tag; use `todo list +TAG` to preview.

Connections are symmetric: adding `+2` to task 1 also shows `+1` on task 2.
Removing the connection from either task removes it from both.

**List filters:**

  WORD     description contains WORD, case-insensitively
  ID[/ID]  task ID equals any listed ID
  +TAG[/+TAG]  task has any listed TAG
  -TAG     task does not have TAG
  +ID      task is connected to ID
  -ID      task is not connected to ID

IDs and positive tags separated by `/` use OR within that filter group; all
separate filters are combined with AND.

**Storage:**

  The default database is `.todo.sqlite` in the nearest Git root, or the current
  directory outside Git. Set TODO_DB_FILE to use an exact database path.

**Output:**

  Tasks use the stable format `ID DESCRIPTION +TAG +REFERENCE`. Terminal output
  adds color and wrapping; redirected output remains plain, one task per line.
