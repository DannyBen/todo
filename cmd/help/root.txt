Todo - A lightweight project todo list

**Usage:**

  todo add TEXT...
  todo list FILTER...
  todo edit ID [TEXT...]
  todo del FILTER...
  todo help

**Aliases:**

  todo new = todo add
  todo ls  = todo list
  todo rm  = todo del

**Arguments:**

  TEXT    description text with optional tag or connection operations
  FILTER  words, IDs, tags, or connections used to select tasks
  ID      task ID; join multiple IDs with `/`
  TAG     starts with a letter or digit; may contain hyphens or underscores

Spaces between filters mean AND. `/` means OR within one filter group and may
join different filter types.

**Operators:**

  +  Add or Has
     todo edit 12 +defer
     todo list +high

  -  Remove or Doesn't Have
     todo edit 12 -defer
     todo list -blocked

  /  OR when selecting tasks
     todo list +maybe/+consider
     todo rm 3/4/5
     todo rm 3/4/5/+low

After `+` or `-`, an all-digit value is a connection; any other valid value is a
tag. A prefix is special only when the whole token is valid. For example,
`+tag` adds a tag, while the separate words `+ tag` are ordinary text. Invalid
operations and standalone `+`, `-`, or `--` are also ordinary text. Removals
during `todo add` are accepted and have no effect.

During `todo edit`, ordinary text replaces the description. When an edit contains
only tag and connection operations, the existing description remains unchanged.
With no text, `todo edit ID` opens the current description, tags, and connections
in an inline editor. Enter saves the edit and Ctrl+C cancels it. Interactive edits
require a terminal; provide text on the command line in scripts.
Multiple IDs separated by `/` receive the same non-interactive edit atomically.
`todo del` accepts the same filters as `todo list`, deletes every match
atomically, and prints each removed task so it can be recovered. Use `todo list`
with the same filters to preview.

Connections are symmetric: adding `+2` to task 1 also shows `+1` on task 2.
Removing the connection from either task removes it from both.

**Examples:**

  Add and prioritize work:
    todo add Prepare for deployment +production +now

  Find actionable production tasks:
    todo list +production +now -blocked

  Complete a task without replacing its description:
    todo edit 1 -now +done

  Connect related tasks, then list either one:
    todo edit 1 +2
    todo list 1/2

  Apply the same edit to several tasks atomically:
    todo edit 2/3 +ready -defer

  Preview completed tasks before deleting them:
    todo list +done
    todo del +done

**Storage:**

  The default database is `.todo.sqlite` in the nearest Git root, or the current
  directory outside Git. Set TODO_FILE to use an exact database path.

**Output:**

  Tasks use the stable format `ID DESCRIPTION +TAG +REFERENCE`. Terminal output
  adds color and wrapping; redirected output remains plain, one task per line.
  Set NO_COLOR to a non-empty value to disable terminal colors.
